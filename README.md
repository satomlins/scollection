# Scollection covers

Folder covers for Scott's Collection (Scollection), a set of collections for [AIOMetadata](https://github.com/cedya77/aiometadata)'s collection builder. The collections file links to these images by their raw GitHub URL, so they live here in public.

Each cover is `covers/<collection>--<folder>.jpg`, 1280 × 720.
